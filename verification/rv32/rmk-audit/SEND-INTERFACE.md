## `send_round : SendAt m₀ → Lands B img (SendQ m₀) m₀`

`SendQ m₀ m = Kept m₀ m ∧ (done ∨ yield)`:
- **done:** pc 0x80003fd8 (the unpark site), with [s10] = [0x8002a7f0] = 1;
- **yield:** pc 0x8001e14a, the yield poll, an explicit BOUNDARY:
  - ra = 0x80004324;
  - a0 = 0x8002a7ec, the yield flag, which holds 0, so it is the first poll: it calls `wake_by_ref` through the waker vtable, which is executor code (an lr/sc run-queue push at 0x8001e174);
  - a1 = sp+0x30;
  - a Pending result then leaves the poll via 0x800043b8.

`Kept m₀ m` means:
- quiet;
- same sp;
- every register except ra, s0 and callerSaved;
- RAM outside `SendW sp` = [0x8002a7c4, 0x8002a7f1) ∪ [sp-0x50, sp) unchanged.

`SendW` ⊆ `SessionI.SW` (0x8002a7b0..0x8002a7f4 and sp-0x70..sp), so `extras_keep` should carry `Extras` across the send.
