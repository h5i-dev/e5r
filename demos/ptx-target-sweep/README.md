# Concrete PTX edit experiments

Six individually frozen CUDA originals and directly authored PTX edits. See
[SCOREBOARD](SCOREBOARD.md), [declared plan/domains](PLAN.md), and each target’s
`results/COMPARISON.md`. All six are currently **UNPROVED exploration**. Existing
accepted stencil/unpack artifacts are preserved separately.

These are controlled translation-validation experiments with project-authored
CUDA originals, not extracted production OSS. Transpose starts from textbook
naive uncoalesced stores and reaches tuned-CUDA parity. Xorshift is a handpicked
fixed64 workload; tuned CUDA often wins. Gains over these originals do not
establish superiority over tuned OSS or nvcc broadly.
The other four experiments are timeboxed misses, including nvcc already folding
the affine advance. Original transpose/Laplacian contain unsupported `or.pred`;
no verification acceptance is claimed. An initial transpose shared-address bug
was caught by GPU testing and retained before the corrected artifact was timed.

Reproduce from the repository root after `bash demos/ptx-equivalence/run.sh setup`:

```sh
source demos/verified-packing/env.sh
"$E5R_DEMO_SCRATCH/venv/bin/python" demos/ptx-target-sweep/experiment.py test
"$E5R_DEMO_SCRATCH/venv/bin/python" demos/ptx-target-sweep/experiment.py benchmark
"$E5R_DEMO_SCRATCH/venv/bin/python" demos/ptx-target-sweep/experiment.py report
```

An optional target name follows `test` or `benchmark`. The harness acquires the
shared GPU lock, rejects foreign compute processes, checks immutable hashes,
and retains all predeclared sizes. Seven repeats, graph replay and ordinary
CUDA events use preallocated buffers. Raw measurements include launch geometry,
versions, resources and repeat samples. Tests cover independent CPU results,
all16 independent four-byte input/output offsets, tails and canaries.
`author.py` and `author-xorshift.py` document construction and refuse to overwrite
frozen artifacts. Candidate PTX is never generated by compiling candidate CUDA;
CUDA sources named tuned/iterative are separately labeled comparators.

Project-authored kernels/references; no external kernel source copied. Python
and GPU dependencies are inherited from the pinned packing demo environment.
The Lean model does not verify nvcc, ptxas/driver JIT or hardware. Tests and
benchmarks are empirical evidence, separate from universal proof acceptance.
